# T31 每台车的资料

在项目“车辆”页打开真实车号的“车辆记录”，即可查看该车的资料。到场点检、车辆参数包以及适用调度平台的逐车参数记录均来自项目资料清单；界面按资料编号、周次显示状态、截止时间与计算依据、负责人及版本。未满足真实事件或周次条件的要求显示待生成说明，不创建另一份资料。

到场点检 6.1 的截止时间由统一资料期限服务按该车 `arrived_at` 日历锚点加 24 小时计算。原到场记录只有日期，界面明确说明未记录实际到场时刻；清除某车到场日后，该车待交点检恢复等待事件，其他车不变。已提交版本的截止依据快照按 T23 规则保留。

“上传资料/新版本”使用原资料实例 ID，新增不可变版本；资料清单和车辆页读取同一组版本。旧版本可下载核对，项目空白模板仍可下载。提交即可，审核不决定提交状态。切换车辆或项目后的迟到响应不会覆盖当前记录；保存期间禁止重复提交，失败保留选中文件与版本说明供核对。

“在资料清单查看此车”链接使用真实 `vehicle_unit_id` 筛选，不能用车型数量或显示编号冒充车辆身份。服务端的 `GET /projects/{id}/documents?vehicle_unit_id={uuid}` 先核查项目可见性和车辆真实归属，再投影同一套资料、版本和期限提醒；不生成新实例，不返回无关未归类文件，保密规则保持原约束。

车辆资料提交继续要求资料提交权限和项目成员关系，准备阶段仍可交资料；不会借用车辆矩阵的现场执行状态限制，也不会因此勾选车辆进度或改变项目状态。权限撤销、历史只读及项目写保护仍由同一组资料接口执行。
