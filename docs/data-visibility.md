# 数据可见性说明

每次请求同时校验当前账号状态、动作权限与项目是否存在。菜单隐藏只用于导航，后端仍逐次判权。

## 项目数据

每个启用账号都能看到全部项目并做全部项目工作（见[账号与权限](accounts.md)）。写入还需要项目处于允许的阶段，并带上读取时的版本号。

保密资料只对项目负责人和明确指定的人可见，系统管理员、上传人和提交人也要明确指定，见[保密边界](confidential-documents.md)。

## 私有数据

通知和本人记录按所有者保护。功能下线时按所有者隔离加密保全的历史资料不通过项目附件公开。

## 全局配置

项目模板、车型库和使用反馈每个账号都能维护；账号、节假日、通知渠道、备份、存储和软件更新只有系统管理员能维护。
