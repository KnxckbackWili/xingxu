# 数据可见性说明

每次请求同时校验当前账号状态、系统操作权限与项目可见范围。菜单隐藏只用于导航，后端仍逐次判权。

## 项目数据

所有启用的内部账号都能查看全部项目并登记现场事实；项目维护动作按账号角色、项目经理和技术负责人职责以及系统权限判断。只读账号只能查看和导出。

项目文件、任务、日程、准备、问题、物品和车辆数据沿用项目边界；写入还需要相应业务能力、生命周期及版本检查。账号角色、成员关系和成员操作授权分别管理。

## 私有数据

个人日程、通知及个人记录按所有者保护。人员不可用时段的详细原因只向本人及有明确管理权限的人开放；用于安排冲突的汇总不扩大详情读取权限。AI 结构化整理任务仅向发起者返回进度与结果。

T03 历史聊天、记忆、无法确认归属的收集箱资料和个人演示项目按所有者隔离加密保全，读取方式见 功能下线说明。这些导出不通过项目附件或外部工具公开。

## 全局配置

用户账号、模板、车型、通知渠道、备份和外部工具凭据分别使用对应系统权限；管理入口与真实账号资格同时校验。人员安排的业务权限不自动授予账号或权限管理资格。

## 外部工具

Agent Token 绑定当前启用账号，其 scope 限制可调用工具。业务结果仍按该账号的项目范围和能力过滤；工具只提供只读查询与回滚式排程模拟。文件目录查询不等于文件正文下载授权。令牌停用、过期或绑定账号停用均即时拒绝访问，见 [Agent 接入](ai-internal-api.md)。
