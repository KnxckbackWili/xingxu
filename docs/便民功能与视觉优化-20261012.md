# 便民功能与视觉优化

> 本文引用的 QA 回执描述历史时点，原件已[归档](evidence-archive.md)；当前 v3 操作请从[文档入口](index.md)开始。

本轮围绕“更快找到项目、少翻清单、手机更好点”改进日常操作，同时修复状态权限并发与备份还原失败的边界。此前提及的“删除还原与编辑撤回清单”原文未包含在本次来源提交中；现行规则见[项目回收站](project-retention.md)。

## 使用变化

- **收藏项目**：在项目列表的卡片或表格点击星标，再点“我的收藏”筛选常用项目。搜索、状态和进度可以组合使用。
- **最近浏览**：项目列表显示最近查看的三个可访问项目，可直接回到上次看的日程、任务或资料页。“清空记录”只清最近浏览，保留收藏。
- **刷新列表**：点页面上方“刷新”获取最新项目，同时保留搜索条件与筛选。
- **我跟进的事项**：准备清单可按自己的内部跟进人身份筛选；默认只看待处理，取消该选项可查看已完成的事项。
- **手机排版**：项目长名称最多显示两行，状态单独排列；弹窗确认与取消按钮至少 44px 高，收藏按钮为 44px，便于触控。

收藏和最近浏览是当前浏览器内的个人偏好，按账号分别保存，暂不跨设备同步。本地只保存项目 ID 和允许的页面名称；展示时使用服务器当前可访问的项目列表。浏览器禁止存储时会提示仅在本次使用中保留。最多收藏 50 个项目，最近记录保留 8 个、展示 3 个。

## 整改清单

| 编号 | 原问题或不便 | 本轮处理 | 验收方式 |
| --- | --- | --- | --- |
| 1 | 常用项目需要重复搜索 | 增加收藏与组合筛选；切换账号隔离偏好 | 网页收藏、取消、筛选、刷新、账号切换；组件回归 |
| 2 | 返回项目后需要重新找上次页面 | 最近浏览直接继续工作；清空不影响收藏 | 网页日程往返、刷新及删除还原；存储、权限变化回归 |
| 3 | 列表缺少主动刷新入口 | 增加刷新按钮，保留筛选，迟到响应不能覆盖新账号/新权限列表 | 网页组合筛选刷新；并发请求回归 |
| 4 | 手机项目名称与状态挤在一起 | 长名称两行，状态另行，工具栏分组；明暗主题保持清楚 | 390、700、1280px 网页截图与尺寸检查 |
| 5 | 部分手机确认弹窗按钮只有 40px | 修正覆盖规则，手机确认/取消统一至少 44px | 删除确认弹窗 40→44px 网页红绿验证；桌面尺寸保持 |
| 6 | 准备事项多时难找自己负责的内容 | 新增“我跟进的事项”，按用户 ID 筛选；支持组合与空态清除 | 网页分派和筛选；同名成员、只读和切换账号回归 |
| 7 | 状态请求等待锁期间撤权/停用仍可能成功 | 获锁后重新读取账号及权限，重新检查停用、访问范围与归档禁止 | 真实 API 两事务竞态回归；网页正常推进与撤权后按钮消失 |
| 8 | 还原失败可能自动启动写服务，停止/复制/启动错误可能被吞掉 | PG 与 SQLite 先确认停写；数据替换失败保持维护。前置失败只恢复原本运行的服务，维护状态重试不误启动；SQLite 明确提示请求提交 | 18 项实际宿主脚本隔离故障注入、7 项既有回归；不改真实数据库 |
| 9 | 周日运行跨月日程测试时，旧断言把本周一算成未来周一 | 日程产品逻辑正确；测试改为固定周日和周一，分别核对当前周一及跨月任务可见性 | 原断言复现失败；22 项日程测试通过，全量再验证 |
| 10 | 上轮测试数误写成 1618 | 按原测试回执更正为 1617，历史结果与本轮结果分别记录 | 原始测试回执核对 |
