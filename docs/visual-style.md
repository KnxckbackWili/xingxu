# 界面样式

全站只有一套外观，改页面时沿用它，不在页面里另起颜色、边框和圆角。

## 样式分层

- `frontend/src/styles/tokens.css`：最先加载。颜色、圆角、阴影、页面间距只在这里定义（浅色与深色各一组 `--agv-*` 变量）。
- `frontend/src/main.tsx`：Ant Design 主题取同一组数值。
- `frontend/src/styles/theme.css`：最后加载。卡片、表格、标签、按钮、输入框、页签的统一外观。
- 各页面的 CSS 只管本页的排版，颜色一律用 `--agv-*` 变量，不写死色值。

## 规则

- **卡片**：白底、`--agv-radius-lg` 圆角、`--agv-shadow-sm` 柔和阴影，不加描边；卡片里再嵌的表格和列表不重复加底色和阴影。
- **表格**：表头透明、小号次要色文字；行间一条浅分隔线，悬停浅灰。直接放在页面上的表格自带卡片外观。
- **状态**：用 `Tag` 表示，统一为无描边的圆角色块——绿＝完成，蓝＝进行中，橙＝提醒，红＝逾期或严重，灰＝未开始。
- **人**：出现人名的地方用 `components/Person.tsx`（`Person` 或 `PersonAvatar`），同一个人在全站是同一种颜色的头像。
- **切换**：项目内一级页签是下划线页签；页内的二级切换（如“工作项 / 周计划”）是分段切换。
- **主操作**：每页最多一个主按钮；其余用默认按钮或图标按钮。
- **手机**：与电脑同一套组件，卡片改单列，点按区域不小于 44px。
- 深色模式由同一组变量切换，新增样式后两种模式都要看一眼。
