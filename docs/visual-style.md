# 界面样式

全站只有一套外观，改页面时沿用它，不在页面里另起颜色、边框和圆角。

## 样式分层

- `frontend/src/styles/tokens.css`：最先加载。颜色、圆角、阴影、页面间距只在这里定义（浅色与深色各一组 `--agv-*` 变量）。
- `frontend/src/styles/base.css`：盒模型、正文字体、链接等几条全站基础规则。
- `frontend/src/main.tsx`：Ant Design 主题取同一组数值。
- `frontend/src/styles/theme.css`：最后加载。卡片、标签、按钮、输入框、弹窗的统一外观。
- 各页面的 CSS 只管本页的排版，颜色一律用 `--agv-*` 变量，不写死色值。

## 规则

- **表格只有一个**：`components/Grid.tsx`。所有清单都用它，不另写表格和表单。格子平时像普通文字，点中才出现边框；离开自动保存；最后一行回车新增。
- **手机**：同一张表在 640px 以下自动变成卡片——主栏目是卡片标题，打勾变成一排带文字的大按钮，其余栏目带小标签。点按区域不小于 44px，不出现横向滚动。新增栏目时给 `Column` 填好 `label`，手机卡片和读屏都靠它。
- **卡片**：白底、`--agv-radius-lg` 圆角、`--agv-shadow-sm` 柔和阴影，不加描边。
- **缺口**：还差的用 `--agv-warning` 的浅色块，齐了用 `--agv-success` 的文字。全站只有这两种状态色加一个危险色（删除）。
- **状态**：只有两态的东西（问题没关 / 已关、资料已交 / 没交）用圆角色块；打勾用 `CheckCell`。
- **人**：出现人名的地方用 `components/Person.tsx`（`Person` 或 `PersonAvatar`），同一个人在全站是同一种颜色的头像。
- **主操作**：每页最多一个主按钮；其余用默认按钮或“⋯”菜单。
- **新增和改名**不弹表单：直接在行里写；只有新建项目、新建账号、导入这类要填多栏或要确认的才用弹窗。
- 深色模式由同一组变量切换，新增样式后两种模式都要看一眼。
