# 员工一页说明

员工能看到全部项目、做全部项目工作。按钮能不能用以服务端当前判断为准。

1. **建项目。** 在项目列表点“新建项目”，填名称、实施周期并选模板即可。进入项目后按“准备清单”补全客户、地点、车型、资料和周计划，核对现场时区。新项目从“准备”开始。
2. **核对资料。** 在“资料”按阶段核对必需项和截止。选资料项上传真实文件，一份文件可交多项，历史版本保留；不适用须填理由。6.2 生命周期表、6.9.3 内部联系单和 9.2 物品表可从当前记录生成。
3. **登记真实车辆环节。** 在车辆页找到实际车号，勾选已完成环节并填实际日期，可多选车辆批量登记。安全检查必须真实通过，普通失败或不适用也要写明原因。
4. **登记本周工作。** “我的本周”列出已发布的工作和要交的资料，谁做完谁登记。完成日期、登记时间分别保存；修订和撤回都留痕。
5. **上报并跟进问题。** 填真实现象、性质、涉及车辆和照片；事故、质量问题会产生相应资料和时限。“已解决”仍等报告人、项目负责人或系统管理员关闭。
6. **推进项目状态。** 准备 → 现场实施 → 验收中 → 已完成 → 已归档，每步按列出的缺项核对后人工确认；上传、报工和百分比不会自动推进。签单日期填单据上的业务日期。
7. **保全。** 删除项目先进回收站，可还原；永久删除由系统管理员在核对完整加密备份后操作。

大文件分片上传可续传；本地等待不等于已提交，成功后在资料版本里核对。规则细节见[资料](project-documents.md)、[人工状态](project-lifecycle-v3.md)、[车辆](vehicle-progress.md)、[本周与记录](field-week.md)。
