# 页内子菜单可见性修复（2026-09-16）

> 本文引用的 QA 回执描述历史时点，原件已[归档](evidence-archive.md)；当前 v3 操作请从[文档入口](index.md)开始。

## 问题与处理

此前展开了项目导航，但页内仍沿用单行 Ant Design 标签栏。在 390px 手机视口复现：项目设置中的「任务调整」「成员」被挤出可见区域，用户需要发现溢出菜单才可访问。

- 新增 VisibleTabs：页内标签按可用宽度换行，显示完整文字，不把入口收入省略号。保留受控切换、禁用状态、键盘方向键/Home/End 和标签与面板的无障碍关联。
- 全部现有 Ant Design Tabs 使用处改用统一组件，包括项目设置、任务详情、现场信息、交付、动态、模板编辑、人员、统计、个人页面及 AI 助手。
- 项目任务阶段、模板实施范围、模板编辑阶段及移动端任务内容默认展开；保留手动收起。
- 导出页「其他导出、备份与克隆」默认展开，直接呈现工具。

## 验证

- 真实浏览器：390px 项目设置五个标签全部可见，点击「成员」进入成员管理；任务抽屉三个入口全部可见，点击「交付文件」正常显示文件操作。
- 320px 检查项目设置、模板、人员、账号、统计页面，所有页内标签边界均在视口内。
- 新增可复用标签组件测试：受控切换与面板关联、键盘跳过禁用项、多组 ID 隔离。更新原本依赖折叠初始状态的回归测试。
- 构建通过；49 个测试文件、249 项测试通过（maxWorkers=2）。一次默认并发运行中，未改动的问题上报测试遇到短暂提示消失的时序失败；限制并发后全量通过。
- 本轮仅前端改动，无数据库迁移。
