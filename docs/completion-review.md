# 问题闭环、验收与资料交付

项目推进到已完成或已归档时不再核对证据，下面这些只是记录本身的规则。

问题仅关闭或作废算闭环，已解决仍待确认。每个账号都可以开始处理、填写进展和解决说明，关闭/作废由项目负责人、原报告人或系统管理员操作，作废必须填写理由。问题不设处理时限。

验收记录保留最新有效结论和范围校验。选择本项目可读取的真实验收附件时，同时提交已有的7.1项目验收单实例；同一附件不会重复增加相同的当前资料版本。无附件的验收记录不能替代必需资料附件。

资料页可勾选有真实提交的资料并下载所选最新版本。压缩包只包含所选资料的最新原件和清单，同一个文件被多项引用时只收一份；清单写明资料ID、版本ID、附件ID及实际字节哈希。整批校验项目归属、资料和文件可读性及原件大小/哈希，任何一项缺失或无权限都拒绝整包，不静默漏项。源文件分块读取，压缩结果超过8MiB后转临时磁盘，响应结束释放临时文件。

默认交付Excel的六张表及完整JSON/项目包的保全边界见[项目交付工作簿](project-delivery-workbook.md)。
