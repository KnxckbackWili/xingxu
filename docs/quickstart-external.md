# 外部人员一页说明

项目负责人会提供带有效期的只读链接。你无需内部账号；可见范围由该条链接决定。v3 仍待最终部署验收，使用时以负责人提供的实际可用地址为准。

1. **打开链接。** 查看项目进度或车辆进度；默认只开放这两类。链接本身是访问凭据，妥善保管，按约定转交。
2. **查获准资料。** 只有负责人明确选择的签单、阶段资料或指定资料才会出现。只能下载当前获准的最新文件；看不到内部备注、审核内容、人员身份或历史原件。
3. **核对更新时间。** 看板反映服务端当前状态，不能由外部直接修改。车辆进度不等同内部检查原文；资料空白或未显示不代表内部从未产生该资料。
4. **到期或撤销后联系负责人。** 刷新会重新核对授权；链接到期、撤销或项目范围变化后可能失效，无法自行扩大范围。已下载文件不能被系统远程收回，请按双方要求保存或销毁。

保密和“永不对外”资料始终不可见。每次查看和下载都会留访问记录。需要更多内容、纠正记录或处理业务问题，请联系项目负责人；外部链接不提供提交、审核、状态推进或管理功能。

负责人设置规则见[外部只读查看](external-view.md)。
