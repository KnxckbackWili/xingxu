# 项目经理一页说明

适用于已获项目维护权限的负责人。按钮是否可用以服务端当前授权为准；v3 仍在总验收，周计划详细操作待 T40 页面冻结后补齐。

1. **建立项目。** 在项目列表点“新建项目”，填名称、实施周期并选模板即可创建；进入项目后按“准备清单”补全客户、地点、车型、人员、资料和周计划，并核对现场时区与调度平台。新项目从“准备”开始。
2. **落实人员与资料。** 进入项目，维护成员和负责人；在“资料”按阶段核对必需项、负责人、截止与未归类文件。旧资料标“待分类”时先查来源，再明确分类，不能按旧阶段编号猜新阶段。
3. **提交与核对。** 选资料项上传真实文件，一份文件可对应多项；可查历史版本、空白模板和可选审核。不适用须填理由，退回须说明，不能审核自己上传的版本。6.2 本周生命周期表、6.9.3 内部联系单和 9.2 物品表可从当前真实记录生成。
4. **核对计划并跟进现场。** 旧模板车辆工作若提示“未关联环节”，到“计划 → 工作项 → 编辑”选择真实车辆环节，或先改模板再带入；未关联时初稿会提示并跳过完成目标，不能按名称猜成默认五步。车辆页按真实车号登记分批到场，核对逐车环节和安全检查。旧数量若显示“车号未知”，查原凭证再认领，不能再增加一遍完成数。问题只有关闭/作废算闭环，事故与质量问题会触发真实资料要求。
5. **明确推进状态。** 按准备 → 现场实施 → 验收中 → 已完成 → 已归档逐次核对门禁，处理列出的缺项后由有权限的人确认。上传、报工和百分比不会自动推进。签单实际日期填单据所载业务日期；上传时间不代替发生时间。停工与恢复都需依据。
6. **分享与保全。** 外部查看默认仅项目/车辆进度，逐链接选择范围和到期日；保密始终不可外发。删除先进入可恢复回收站，永久删除需有完整加密备份。大文件上传和清理确认前核对范围与变化预览。

遇到无权限、版本冲突或缺文件，保留输入并按提示核对；系统不可见项目不会因手册而开放。规则细节见[资料](project-documents.md)、[人工状态](project-lifecycle-v3.md)、[车辆](vehicle-progress.md)、[分享](external-view.md)。
