## 改动

- 共享界面：统一蓝色、灰白背景、圆角、细边界与阴影；桌面导航使用分组选中态，支持背景模糊的浏览器显示半透明顶栏，其他浏览器保持实色。手机导航仍遵循既有 104px / 44px 偏移。
- 工作台：常用入口增加方向提示；统计数值突出，待办、筛选与项目表分层。窄屏控件保持触控尺寸，长项目名及风险标签允许换行。
- 项目列表：筛选与卡片/表格切换分区；卡片把收藏放在标题旁，将进度、客户地点、周期和负责人组织成更清楚的层级；表格横向滚动限制在自身区域。
- 项目菜单：细化边界、分组、间距与选中态，保留原入口、展开和键盘操作。
- 现场端：折叠任务的标题、项目与数量分开，展开后的数量操作独立成组；状态提醒、资料和离线记录使用主题颜色。我的项目和填报记录卡片减少视觉干扰。
- 深色补修：实测“查看项目”描边按钮文字为 `rgb(23, 88, 200)`，在暗底上偏暗；改为 `rgb(155, 189, 255)`。默认进度条取消旧全局强制绿色，尊重主题及页面提供的风险色。

权限判断、接口、业务条件、存储键、数据库结构和依赖版本保持。后端只有 APP_VERSION 默认值由 2.3.5 更新为 2.3.6。成功/异常进度条与桌面卡片悬停的部分历史样式仍保留，本轮没有重构整个历史 CSS 文件。
