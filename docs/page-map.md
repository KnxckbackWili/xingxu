# 系统页面与入口清单

管理人员和现场人员使用同一个界面外壳：同一套侧栏（手机为底部标签）、同一个项目页。每个账号看到哪些入口，由全系统权限、路由守卫与项目能力共同决定；菜单隐藏不替代路由或后端判权。路径与接口沿用原契约，旧地址按下文兼容跳转。历史版本的页面说明不再作为当前导航依据。

## 先找入口

| 位置 | 当前入口 | 怎么使用 |
|---|---|---|
| 侧栏（桌面）/ 底部标签（手机） | 工作台、项目、问题、人员、消息、设置 | 按权限显示；手机底部显示前四项和“我的”，其余入口在“我的”面板里 |
| 顶栏“查找功能” | 全部可访问的主入口与设置项 | Ctrl/⌘ K 打开，可按名称、用途或旧名称搜索；Escape 关闭后焦点回到触发按钮 |
| 账户菜单（侧栏底部姓名） | 我的记录、设置、二次验证、修改密码、深浅色、使用反馈、退出登录 | 退出前若有未同步的离线记录会先确认 |
| 顶栏右侧 | 上传队列、通知铃 | 上传队列只在有任务时出现，并显示待传数量 |
| 项目页签 | 概况、计划、车辆、资料、问题、现场、更多 | 项目阶段条显示五个阶段（准备、现场实施、验收中、已完成、已归档）和当前位置；“更多”收报告与记录、导出、项目设置 |

## 登录与公共页面

| 路径 | 页面与首要用途 | 首屏与主要动作 |
|---|---|---|
| `/login` | 登录 | 账号、密码、登录；安全保留被拦截的原目标地址，按角色选择默认落地 |
| 无权限 URL | 403 | 说明无访问权限并给返回入口 |
| 不存在 URL | 404 | 返回首页；项目不可见或不存在时使用不泄漏原因的友好提示 |

有管理工作台权限的角色默认进入 `/pm/dashboard`；实施、实习角色进入 `/worker/week`。两者在侧栏里都叫“工作台”。

## 主入口页面

| 当前名称 / 路径 | 用途 | 首屏与主要动作 |
|---|---|---|
| 工作台 `/pm/dashboard`（管理） | 先处理事情，再看项目 | 一个“需要处理”清单汇总逾期/本周资料、逾期或未知计划、待办问题和签单，按类别筛选；旁边是“我的本周”，下方是“我的项目”和折叠的统计。某个来源未读取时明确提示，不显示成“没有待办” |
| 工作台 `/worker/week`（现场） | 本周要做的工作与登记 | 提醒合并为一条；按项目列出本周工作，登记实际完成、认领、上传当期资料；检查项折叠展开；“查看项目”进入共用项目页 |
| 项目 `/pm/projects` | 打开、新建、导入可见项目 | 搜索、状态筛选与卡片/表格；“新建项目”一屏填写名称、周期和模板后直接进入项目；物品总览、回收站为右上图标 |
| 问题 `/worker/issues` | 跟进可见项目的问题 | 上报与跟进；状态写入按能力 |
| 人员 `/pm/people` | 安排人员与查看负荷 | 人员日程、看板、成员与名册；`/pm/my-schedule`、`/pm/team-schedule` 跳到对应视图 |
| 消息 `/pm/messages` / `/worker/messages` | 查看通知并回到对应工作 | 未读/类型筛选、详情、标记已读 |
| 设置 `/pm/settings` | 低频配置集中一页 | 按下表分组列出当前账号可进入的设置；没有任何设置权限时不显示此入口 |
| 我的记录 `/worker/my` | 本人实际记录、协助与修订历史 | 账户菜单进入；允许撤回的记录按原契约处理 |
| 使用反馈 `/pm/feedback` / `/worker/feedback` | 反馈软件使用问题 | 账户菜单进入；管理人员另可处理反馈列表 |

### 设置页分组

| 分组 | 页面 |
|---|---|
| 团队与权限 | 账号 `/pm/users`、成员权限 `/pm/permissions` |
| 项目配置 | 项目模板 `/pm/templates`（左侧模板列表，右侧当前模板的工作项、资料要求、采购库、车辆环节；可“用此模板新建项目”）、车型库 `/pm/vehicle-types`、节假日 `/pm/holidays` |
| 数据与安全 | 备份与恢复 `/pm/backups`、存储 `/pm/storage`、项目回收站 `/pm/project-recycle-bin` |
| 系统 | 通知设置 `/pm/notification-channels`、外部工具接入 `/pm/ai-tokens`、系统更新 `/pm/system-updates` |

每个设置项保留原有路由权限；设置页只是入口集合。

### 兼容跳转

- `/worker/today`、`/worker/schedule` → `/worker/week`（保留 `project_id` 参数）。
- `/worker/projects` → `/pm/projects`；`/worker/projects/:projectId` → `/pm/projects/:projectId/overview`。现场人员原本就能读项目页，权限不变。
- `/worker/records`、`/worker/stats` → `/worker/my`。
- `/pm/stats` → `/pm/dashboard#statistics`；`/pm/progress` → `/pm/dashboard`；`/pm/ai`、`/pm/ai-assistant`、`/pm/governance` → `/pm/projects`。

## 项目内页面

路径前缀统一为 `/pm/projects/:projectId/`；项目可见账号可读，写按钮由项目能力与阶段决定。

| 页签 | 路径段 | 用途与首屏 |
|---|---|---|
| 概况 | `overview` | 准备阶段显示“进入「现场实施」还差 N 项”清单（基本资料、车型、人员、资料清单、周计划、发车前资料确认），其后阶段显示“现在要处理”；节点时间表（计划/实际，登记/更正/清除）和验收；侧栏是进度、待处理计数和最近记录 |
| 计划 | `plan` | 主按钮“添加工作项”，添加阶段/从模板带入/刷新在“更多”；搜索与筛选（全部/未完成/待检查/车辆工作）；默认只展开第一个未完成阶段；每行完成动作加“⋯”菜单（详情与检查、编辑、历史来源） |
| 车辆 | `vehicles` | 车辆进度表、逐车检查、资料与问题履历 |
| 资料 | `documents` | 按阶段的页签（显示待交数量）加“全部”；每行主动作是提交文件/提交新版本，指派、版本记录、空白模板、采购明细、验收、保密范围、不适用、撤回在“⋯”菜单；未归类文件有提醒横幅 |
| 问题 | `issues` | 待解决/待关闭优先；上报、指派、处理、关闭 |
| 现场 | `inventory`、`handover` | 物品（默认）与联系人与入场 |
| 更多 | `reports`、`history`、`export`、`edit` | 报告与操作记录、导出、项目设置 |

旧路径段继续解析：`tasks`、`schedule` → 计划；`delivery`、`files`、`archive`、`preparation` → 资料；`site` → 车辆；`activity` → 操作记录；`team`、`start` → 概况。深链接 `issues?report=1` 保留上报入口。

## 共用界面能力

| 组件 | 入口 | 行为 |
|---|---|---|
| 通知铃 | 顶栏 | 未读数字、最近通知、查看全部与已读处理 |
| 上传队列 | 顶栏（有任务时） | 断点续传、失败重试；不显示伪成功 |
| 离线队列 | 现场工作台 | 本机按账号保存待同步记录，恢复网络后提交 |
| 查找功能 | 顶栏 / Ctrl⌘K | 与侧栏、设置页同源，只列当前账号可访问的入口 |

### 图标与说明的约定

- 页面和分区标题下的说明文字收在标题旁的 ⓘ 里，悬停、聚焦或点按查看；读屏软件照常读出。
- 刷新、编辑、查看、删除、导入导出等常规操作用图标按钮（`components/IconAction.tsx`），悬停显示名称，按钮的无障碍名称与原文字相同。
- 新建、提交、标记完成、推进状态等主要业务动作保留文字按钮；警告和错误提示保留完整文字，只有常驻的说明类提示收成一行加 ⓘ。
- 项目页签、设置页入口以图标为主；设置页每项是一块图标卡片，用途在悬停提示里。

新增页面或入口时，应同步 `constants/nav.ts`、`layouts/pmMenu.tsx`（主入口与设置分组）、`constants/projectNav.tsx`、路由守卫与本清单。
