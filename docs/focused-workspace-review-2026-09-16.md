# 信息层级与工作区减负 · 2026-09-16

## 问题

此前的布局只整理了间距，仍将全站菜单、项目菜单、子页标签同时呈现；总览重复展示启动清单、准备完成量、风险标签和进度。用户进入项目需要先理解界面，再寻找下一步。

## 本次调整

- 项目内移除全站侧栏和项目侧栏，统一为「总览 / 准备 / 任务 / 日程 / 问题 / 交付」。全站入口在左上角；现场信息、团队、动态、设置与导出在「更多」，各子页保留自己的标签及原深链。
- 总览只突出一个当前行动、项目进度和分类提醒。完整启动清单、阶段进度、趋势、动态按需展开；暂停项目保留明显提示和恢复入口，状态切换仍走原服务端校验。
- 现场人员的准备期行动改为查看日程，不再引导其访问无权限的任务配置、准备或动态页面。
- 全站导航保留常用入口，其余按「人员与物品 / 工具与记录 / 管理与设置」折叠；按角色检查入口集合，未删除原有功能。
- 首页优先显示待办和项目队列，决策、人员与统计细节后移并折叠，趋势不再默认加载；项目列表移除重复状态与风险标签。
- 模板改为选择一个方案后查看内容，移除独立模板列表；创建项目、编辑模板紧邻当前方案。编辑中禁用切换、复制和导入，避免尚未保存的内容被覆盖。
- 项目任务页移除重复的方案说明卡；日程保留下达主操作，将规则和重排归入「调整日程」；准备项一次展开一组，筛选后展示首个匹配组。
- 修复模板搜索后修改任务错位：编辑、删除和检查项操作按原模块与任务的位置执行，不使用过滤后的数组位置。
- 手机保持同一条项目导航；模板选择框单独占一行。深色模式的折叠面板和分隔线使用主题边框。

## 验证

- 前端 48 个测试文件、243 项测试通过；生产构建通过。
- 新增模板筛选编辑回归：只修改匹配任务，保留未匹配模块及相邻任务。
- 回归角色导航完整性、二级深链选中、项目资料抽屉、启动清单和图表展开、草稿状态切换范围、现场人员入口。
- 浏览器实际点击：项目更多 → 现场信息 → 物品；交付 → 项目文件 → 验收归档；项目中的全站导航 → 模板中心。
- 1440 像素桌面检查项目、首页、任务、日程、准备和模板；320/390/768 像素检查上述页面及项目列表，未发现整页横向溢出。宽表继续在表格内部横向滚动。
- 已查看浅色、深色和手机截图，记录位于 `docs/screenshots/focus-2026-09-16/`。

本轮调整前端展示与交互，未修改数据库结构、后端状态规则和接口权限。折叠后的功能需要多一次展开，换取日常页面更少的同时可见选项；这不代表所有未来业务场景已穷尽验证。

## 部署

部署目标仍为独立 Docker 实例 `agv-pm-7001`，宿主机 `0.0.0.0:7001` 转发至容器 `8000`，外部访问 `https://agv.arrowwood.top:8773`。发布前用 SQLite backup API 备份现有数据库，保留已有项目数据；不操作 8002 实例。
