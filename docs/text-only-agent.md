# 文字整理与外部 Agent 只读接入

Agent 与 MCP 保留在“全部功能 → 管理设置 → 外部工具接入”。同一设置页展示既有 AI 月度预算和用量，不建立第二份账本或预算配置。限额沿用部署配置；外部 Agent 自身的模型费用由其提供方计量，读取项目不会启动系统模型调用。

工具只读取当前账号获授权的事实，供外部工具整理文字。新增资料清单 `documents_read`、车辆进度表 `vehicle_progress_read`、本周待交资料 `documents_due_this_week`。本周按项目时区和 T23 截止规则计算，不在查询时补建期次。资料、版本及附件使用 T26 共同权限判断；每次获授权的保密元数据读取继续审计。工具不提供原始恢复快照、退休导出、文件正文或磁盘路径。

旧数量任务、按天日程、排程预览、准备评审及开工安排工具退出目录。任务/排程/准备的旧 scope 在原令牌记录中保全，但认证和展示时不再生效，新建/编辑令牌也不能请求它们。现有状态、车辆检查、资料提交、权限、外部分享和退休功能都没有 Agent 写工具；写工具注册会明确失败。HTTP 和 MCP 目录根据当前令牌 scope 返回，同一调用在执行前重新核对账号、MFA、令牌启停/期限、当前 scope 和项目可见性。

项目、模块、数量、日程等旧结构化草稿入口 `/ai-projects/organize*`、模型连接探测和旧 skill 下载均返回 410。旧排队回调不会重新发起模型调用；已完成的本人历史结果保留只读，不自动应用到业务。未增加系统内纪要/周报起草，也不会自动保存当期资料版本。如日后增加纯文字建议，仍须由人员核对后使用正常资料入口保存。

HTTP `/api/agent/*` 与 MCP `/api/ai/mcp/` 仍使用专用 `agv_ai_` 凭据，不能用网页 JWT 或外部分享会话替代。令牌只显示一次，服务端仅存哈希；角色或权限收回立即影响后续调用。接口响应 private,no-store，不进入普通业务离线缓存。普通外部分享账户不能取得内部 Agent 身份。

资料工具不会发还来源快照、事件来源原始载荷或可写权限选择器。车辆进度只返回真实环节事实和汇总，不带旧任务来源、原始迁移载荷、备注或业务修改入口。项目摘要采用当前进度与里程碑日期，不再暴露旧按天排程版本/计划数量接口。
