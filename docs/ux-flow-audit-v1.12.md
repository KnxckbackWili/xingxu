# 系统使用流程走查与整改记录（v1.12）

> 走查目标：把每个页面的内容、用户要做什么、当前最大的注意力负担梳理出来，并做第一轮「少看、少点、少判断」整改。

## 一、页面逐项走查

### 1. 登录 `/login`
- 有什么：账号、密码、过期提示、版本号。
- 用户要做什么：登录即可。
- 问题：无。保持简单。

### 2. 数据总览 `/pm/dashboard`
- 有什么：6 个指标、待处理事项、项目健康、项目状态表、图表。
- 用户要做什么：先看有没有要处理的，再点进项目。
- 问题：管理层只看数字时信息偏多；管理员/PM 的常用动作（新建项目、AI 助手）没有直接入口。
- 整改：顶部增加「新建项目 / 智能助手」快捷按钮；指标和待处理保持第一屏。

### 3. 项目列表 `/pm/projects`
- 有什么：搜索、状态筛选、卡片/表格视图、新建项目弹窗、快捷导入。
- 用户要做什么：找项目；新建项目。
- 问题：创建弹窗把缩写、客户、地点、项目条件等全部平铺，首次创建像填表。
- 整改：只保留「项目名称 + 实施周期」为必填；缩写、客户、地点、进场日期、项目条件收进「更多信息（可选）」，未展开时使用安全默认值。

### 4. 智能助手 `/pm/ai-assistant`（原 AI 助手 + 文档收集箱）
- 有什么：原页面是 5 张技能卡片 + 多个 Drawer；收集箱是独立表格页。
- 用户要做什么：上传文件、AI 归类、AI 整理项目/问题/物品/交接、确认后应用。
- 问题：AI 入口和文件收集箱分离，用户要两边跑；卡片式入口不像对话，不能连续表达需求。
- 整改（本轮重点）：
  - 合并为「左侧对话 + 右侧边栏」。
  - 左侧使用 Ant Design X（开源项目 `ant-design/x`，GitHub 官方仓库）的 `Bubble` / `Sender` / `Prompts` 对话组件。
  - 右侧边栏固定放「项目上下文」和「私人文件收集箱」。
  - 一句话可自动识别能力；结果在对话中展示，点击「打开结构化审核并应用」进入原审核 Drawer，仍然保持“AI 不静默写库”。
  - 管理员/PM 菜单中不再出现两个入口。

### 5. 项目工作区 `/pm/projects/:id`
- Tabs：总览 / 准备提醒 / 执行计划 / 项目日程 / 现场信息 / 问题关注 / 交付 / 项目动态。
- 总览：健康卡、进度、待办、阶段、趋势、报告。要做的：判断项目是否健康。
- 准备提醒：准备清单、四日期、采购、评审。要做的：只处理未完成/阻塞/逾期。
- 执行计划：阶段-模块-任务表、检查项、交付物。要做的：看任务进展。
- 项目日程：日历/甘特、排程规则、确认下达。要做的：生成排程、确认、调整。
- 现场信息：现场信息 / 车辆台账 / 现场物品三个子 Tab。
- 问题关注：项目问题 + 车辆问题合并。
- 交付：交付物 / 项目文件 / 验收归档。
- 项目动态：审计与报告。
- 问题：8 个 Tab 都是完整工作台，第一次进入不知道从哪个开始。
- 整改：保留过程顺序（总览 → 准备 → 计划 → 日程 → 现场 → 问题 → 交付 → 动态），后续继续做「下一步」引导条。

### 6. 人员管理 `/pm/people`
- 有什么：人员看板、人员安排、人员名册。
- 问题：已删除历史排班日历，页面已经比旧版清爽。
- 保持现状。

### 7. 模板中心 `/pm/templates`
- 有什么：模板列表、9 阶段树、准备清单、采购清单。
- 用户要做什么：只有 admin 维护标准流程。
- 问题：低频但复杂度高，属于配置页。
- 保持现状；入口只给 admin。

### 8. 用户管理 `/pm/users`
- 有什么：组织树、用户表。
- 保持现状；入口只给 admin。

### 9. Worker 端
- 今日任务：填报、检查项、交付物、问题、离线同步。
- 我的日程：未来两周。
- 问题关注：我上报/处理的问题。
- 我的：记录 + 统计。
- 问题：现场端已经是 4 个入口，不要继续加功能；保持轻量。

## 二、本轮已完成整改

1. AI 助手与文档收集箱统一为一个「智能助手」页面：对话 + 右侧项目上下文/文件收集箱。
2. AI 对话 UI 采用 Ant Design X（GitHub `ant-design/x`，兼容当前 Ant Design 5）。
3. 原 AI 审核 Drawer 保留为结果确认环节，AI 仍不直接写库。
4. 创建项目表单只要求名称和周期，其余可选项折叠。
5. 数据总览增加新建项目和智能助手快捷入口。
6. admin/pm 左侧菜单合并「文档收集箱 + AI 助手」为「智能助手」。
7. 历史死代码和未使用 import 已清理，开启 noUnused 门禁。

## 三、第二轮整改（12345 全部完成）

1. **项目总览「下一步」卡**：按车型/任务/日程/准备/问题状态给出唯一主行动，并显示「确认车型 → 生成计划 → 排程下达」三步启动进度。
2. **准备提醒 / 执行计划 / 日程页「只看异常」**：
   - 准备提醒默认只看待处理，已完成/不适用/已到货自动隐藏。
   - 执行计划默认只看未完成任务。
   - 日程默认只看未下达条目；全部下达后自动切回全部。
3. **项目创建后逐步引导**：总览启动向导让 PM 按 确认车型 → 生成执行计划 → 排程并下达 顺序操作。
4. **智能助手多轮对话**：
   - 后端新增 `POST /api/ai-projects/chat`，进程内保存每用户会话（TTL 1 小时，最近 24 条）。
   - 前端无明确技能意图的消息走真实对话接口，支持连续追问和项目上下文注入。
5. **Worker 今日任务默认只看“我的任务”**：未分配任务通过「我的任务 / 全部任务」切换查看。
