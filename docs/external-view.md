# 外部只读查看

在项目设置的“外部查看”中，当前项目负责人可以创建、撤销分享并检查访问记录，需同时有项目资料维护权限。系统管理员或协管身份本身不会取得创建分享的权利。归档项目仍可撤销安全授权，不必先恢复业务编辑。

默认只勾选**项目进度、车辆进度表**。其他范围必须明确选中：四类签单（6.10.1–6.10.4）、验收与交付资料（第7–8阶段）、指定资料。第9阶段全周期更新资料需要按指定资料单独选择。签单及阶段范围会包含以后提交的符合范围的最新版本；指定资料仅限选中的期次，以后生成的新期次不会自动加入。每条链接必须有有效期，最长一年；可随时撤销，撤销不可恢复。

链接仅在创建时显示一次，关闭或刷新后不能找回；需要再次提供时撤销原链接并重新创建。持有链接即可读取已选内容，应妥善转交。保密资料和“永不对外”的资料永远不会显示，修改成保密后会立即停止后续访问；同一原件的全部保密资料引用和附件独立限制也参与校验。

外部页面无需业务账号，只有只读看板和经过授权的最新文件下载。项目进度只提供状态、周期与汇总；车辆进度不含内部备注、操作者、来源快照或检查项原文。资料不提供审核备注、内部人员或历史原件。每次打开、刷新和资料下载都记录时间、直接连接IP、内容对象和结果。代理部署应正确配置可信代理边界，应用不直接信任访问者自填的 X-Forwarded-For。

分享到期、撤销、项目软删除、负责人停用、负责人变更或失去授权能力后，已有短期会话也不能继续读取。已下载到接收人设备的文件不能远程收回。外部页面在短期会话到期后清除已显示数据，刷新会重新向服务器核对授权。

## 凭据与接口边界

原始分享令牌为32随机字节，数据库只保存 SHA-256 哈希。链接采用 `/external#token=…`，片段不会进入普通HTTP访问路径；页面进入后立即移除片段，通过固定小请求体向 `/api/external/bootstrap` 核对原令牌。服务器换发最长15分钟、aud/type均限定为 external_view 的只读会话，不发业务 JWT/Cookie。

外部网络模块单独使用 fetch，credentials=omit、cache=no-store、referrerPolicy=no-referrer。凭据仅保留在当前页面内存，不写 localStorage、sessionStorage、IndexedDB、业务离线队列或普通API缓存，不放下载URL。服务端所有外部和分享管理响应均 private,no-store，外部页面及API为 no-referrer。不记录请求体、Authorization、原令牌或会话令牌；反向代理也应保持普通访问日志，不另行记录这些秘密字段。

每次外部请求重新核对原始授权、项目和当前文件范围，并在共同项目锁下采样；撤销与范围变更不能被旧会话跳过。外部会话不能用于内部接口，业务会话也不能替代外部授权。匿名访问使用现有 SQLite/PG 共享限流实现，避免多worker放大额度。

管理接口位于 `/api/projects/{id}/external-shares`，由当前负责人及动作权限共同保护。外部内容仅在 `/api/external/*`。资料下载要求本链接的项目、资料范围、当前最新版本和共同资料/文件ACL全部满足。指定不同项目ID、资料ID或历史版本不会扩大可见内容。

迁移 g3a53b000001 建立 hash-only 分享表和访问事实表，精确父链以修订文件为准。系统加密一致备份保全全部数据；删除前项目加密备份专门保全分享和访问事实，并验证后才允许级联清除。普通JSON/Excel/ZIP及旧公开归档不会包含安全授权记录。恢复私有备份仍属于受信运维边界。
