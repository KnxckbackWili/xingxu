# 恢复入口可见性 · 2026-09-16

上一轮过度依赖“更多”和默认折叠，用户反馈找不到功能。本轮恢复入口可见性，保留分区、统一间距和清晰的当前操作。

- 项目导航按项目实施、现场协同、交付与复盘、项目操作分行；现场车辆、物品、交接、团队、文件、归档、变更记录、周期报告、项目设置、导出直接可见。
- 原有角色过滤和深链保留；文件页只高亮项目文件，设置页只高亮项目设置。
- 全站导航改回具名、展开的分组；项目内左上角明确显示“全站导航”，手机显示“导航”。
- 启动清单、阶段进度和准备分类默认展开，首页决策与人员概况恢复展开。
- 模板导入/导出恢复可见按钮，编辑期间继续禁用，避免未保存内容被覆盖。
- 排程规则、逾期/受阻重排、重新排程恢复直接按钮；尚无日程时也能先配置排程规则。
- 趋势图仍可按需展开，编辑表单及危险操作继续使用原确认流程。

前端全量 48 文件、246 测试通过；生产构建通过。浏览器验证项目文件 → 验收归档 → 项目设置均可直接进入；全站目录包含 16 个管理员入口，不使用二级折叠菜单。项目中的 17 个管理员入口在 320/390 像素宽度均未隐藏，也无整页横向溢出。截图见 `docs/screenshots/navigation-2026-09-16/`。
