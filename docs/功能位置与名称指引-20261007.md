# 功能位置与名称指引

常用管理工作从顶部“工作台、项目、人员、消息”开始。其他功能点“全部功能”（手机显示“菜单”），输入现在的名称、以前的名称或用途就能找。进入项目后，日常只保留七个入口；低频工具没有删除。

## 第一次使用从哪里开始

- 项目经理：工作台看“现在要处理”→项目打开已有项目或新建。新建依次填写“项目资料、工作内容、确认创建”，保存后是草稿；在概况核对下一步，再明确开始项目准备。
- 项目工作：任务看“做什么、目标多少”；人员确定实际参与者；日程安排“哪天、谁做、多少”。准备清单和进场评审独立核对，排程或进度百分比不会替代阶段确认。
- 现场人员：默认进入“今天”，点工作卡片的“打开填报”记录完成数量。后续安排看“日程”，现场情况看“问题”与“项目”，既有记录看“我的”。
- 找资料：项目“资料”默认全部文件。任务要求提交的文件到“提交资料”；项目收尾结论到“验收”；周报/月报到“报告”。

## 项目七个常用入口

| 现在的位置 | 做什么 | 以前可能见到的名称 |
|---|---|---|
| 概况 | 当前阶段、进展、待处理工作和下一步 | 项目首页、项目总览、项目概况 |
| 准备 | 资料、采购、责任人、进场条件 | 准备提醒、进场准备、准备清单 |
| 任务 | 工作内容、目标数量、检查与任务资料 | 执行计划、项目任务、工作清单 |
| 日程 | 日期、执行人、计划数量、甘特与发布 | 项目日程、执行日程、排程 |
| 人员 | 本项目成员、岗位与操作授权 | 团队、成员、人员安排 |
| 现场→问题 | 上报、处理、确认关闭 | 问题关注、现场问题 |
| 现场→车辆 | 实车状态和故障维修履历 | 现场车辆、车辆台账 |
| 现场→物品 | 位置、保管、库存与出入库 | 物品与去向、现场物品、资产 |
| 现场→联系人 | 客户联系人和入场说明 | 现场交接、交接；页面标题为“联系人与入场” |
| 资料→全部文件 | 查找、上传、下载项目附件 | 项目文件、附件中心 |
| 资料→提交资料 | 提交与审核任务要求的文件 | 交付物、交付材料、交付 |
| 资料→验收 | 验收结论、资料核对、项目复盘 | 验收归档、归档、收尾 |
| 资料→报告 | 周报、月报与打印 | 周期报告 |

只有所在区域的子功能展开，避免每次都显示全部十七项。手机点“项目菜单”使用同一目录。

“更多”里保留：开工向导、项目设置、操作记录、导出。开工向导按工作、人员、日程、进场四步办理；项目设置处理项目资料、协管和移交，基本信息提供撤回与取消撤回；删除在项目列表办理，误删到项目回收站还原。任务目标与执行日期分别到任务和日程调整。操作记录查看谁在何时改过什么；导出优先下载完整项目包。

## 全站其他功能在哪里

| 全部功能分组 | 当前名称 | 以前的名称 / 用途 |

| 资料与统计 | 物品总览 | 跨项目查物品和库存，区别于项目内“物品” |

| 管理设置 | 项目模板 | 模板中心、实施模板 |
| 管理设置 | 账号 | 用户管理、组织与用户管理；账号和组织归属 |
| 管理设置 | 车型库 | 车型字典、车型管理 |
| 管理设置 | 通知设置 | 通知渠道、钉钉配置 |
| 管理设置 | 备份与恢复 | 系统完整备份、备份恢复 |

看到的条目与写操作取决于当前账号和项目权限；新增菜单不会让只读成员取得管理权限。

## 少点几次的常用操作

- 任务列表直接点目标数量或“填写目标”，输入后回车或保存；取消不写，失败保留输入。检查、交付审核和已报工/下达保护照常执行。
- 日程里的日期按钮可查看当前工作总量、发布状态和人工工期；设置与重新安排放在更多，不与“发布日程”混为一个动作。
- 消息在手机点开后显示完整详情和处理按钮，关闭返回原消息位置。
- 配置通知时可直接“取消修改”；项目设置和模板离开未保存内容会先询问，选择继续填写保留输入。
- Ctrl/⌘K 查找；项目里优先查项目功能。Escape 关闭菜单并回到触发按钮，随后可继续键盘操作。

旧链接继续有效：`tasks` 仍是任务，`site` 仍是车辆，`delivery` 仍是提交资料，`activity/history` 仍是操作记录。完整页面和路径见[页面清单](page-map.md)，本轮实际测试见[整体界面重设计清单](整体界面重设计清单-20261007.md)。
