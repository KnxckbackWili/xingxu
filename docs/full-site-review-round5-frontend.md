# 第五轮前端流程复核

基线：本轮新取出的源码快照；日期：2026-09-30。`frontend/src/pages` 当前包含 **55 个非测试 TSX 组件**，比第三轮多出 `MemberPermissions`。页面组件数量不等于独立 URL 数量。

## 证据与验收口径

本轮按入口、读取、写入、失败、并发、离开页面和权限边界检查源码，并为复现的问题补充组件/Hook 回归。以下每行是实际检查范围，不表示该页面每条分支均有自动化测试，更不表示真实浏览器验收通过。

- 实际运行的是隔离 API 回归、Vitest/jsdom 组件测试、TypeScript/Vite/PWA 构建
- 真实云浏览器的 localhost 预览此前被 `ERR_BLOCKED_BY_CLIENT` 阻止；本轮没有绕过，也没有宣称浏览器截图、触屏、视觉、打印或完整键盘 E2E 通过
- 没有操作真实账号、创建真实 token、触发真实 AI/通知提供商、恢复生产数据库或部署 NAS
- 最终完整前后端套件和构建结果以本轮最终验证记录为准；下面的局部测试计数不能相加当作完整套件总数

## 本轮主要修复

1. **会话与离线隔离**：旧账号同步返回不再移除/写入新账号的队列；跨标签页的 owner 变化使本页离线绑定失效；重复 flush 合并同一个请求；被拒记录先成功回队再删除原副本；旧 `fetchMe` 不得恢复已登出的账号或清空刚登录的账号；新登录等待旧 logout 完成
2. **PWA 缓存身份**：worker 缓存键包含已验证账号；无账号标记的请求不进入该缓存，晚到的 A 响应只能写 A 键，B 不会读取它。策略函数有回归，真实 Service Worker 离线场景仍待浏览器验证
3. **现场填报/交付**：数量、修正、检查、交付有同步重入保护；修正重试保留原 UUID；检查携带版本；交付在线/离线携带 task_version；任务页保存使用服务器返回的审核元数据和新 version，连续审核不再用旧整组快照覆盖；同一任务的上传/审核串行
4. **晚到响应/关闭**：项目、任务、文件、交付汇总、归档、准备、物品、统计等读取忽略旧请求；旧项目的回调不能重新加载并覆盖新项目；任务参考预览和交付上传不得把旧结果附到新上下文
5. **权限/状态**：归档项目普通写控件按只读状态隐藏，保留导出与原有显式恢复；已完成/归档项目不显示可执行的排程写操作，停工期间是否重排沿用原后端规则；成员授权使用打开弹窗时的版本/授权快照，不拿后来刷新的版本自动覆盖旧选择
6. **排程**：生成、下达、重排、编辑、规则保存串行；预览未完成/失败不可确认，旧日期预览不得覆盖新日期；日程修改与拖动带 version；取消日程明确显示，未下达筛选和整组移动排除取消项
7. **失败不等于空**：准备、变更记录、统计、人员统计和物品总览/台账加载失败有明确重试状态；文件并发上传按在途数量保持 busy，不在第一份完成后提前解锁
8. **管理员页面**：收集箱重复项目名不自动猜目标、轮询/归档按会话与筛选隔离；备份恢复能力未知/失败时关闭恢复入口；token 和车型管理写操作串行并防旧响应回滚；用户资料与技能原子保存，批量成员写入部分失败明确显示并刷新

## 共享代码与剩余验证边界

额外检查了 App 路由、PM/worker 壳、NAV_ACCESS/PROJECT_NAV、VisibleTabs、工作详情/检查操作、登录存储与 API 拦截器、offline queue/sync、SW 缓存及响应式样式。工作详情检查操作增加同步锁并在 409 后读取新状态；工作面板在权限撤回后的刷新数据下关闭对应提交表单，草稿仍保留。

仍需真实可访问运行环境验证：

- 手机/桌面实际观感、暗色对比、全站键盘焦点、触屏拖动、打印分页
- 浏览器后退/前进、全局导航与开工未保存输入的完整组合；目前有项目内步骤/菜单确认和页面离开提示，并非所有导航形式都已在浏览器证明无丢失
- 安装 PWA 后断网、冷启动、认证重新校验、跨标签切换、服务端重新部署与缓存升级的端到端行为；本轮证明的是队列/缓存身份策略和组件逻辑，不承诺离线冷启动仍可重新认证
- 真实 AI、消息提供商、权限撤回实时推送和大量并行操作；接口最终仍由后端校验，前端不会自行扩大权限
- 项目导出页的快捷 JSON 导入仍保留直接导入体验，未扩展成项目列表同款预检工作台
- 遗留少量行内编辑/弹窗仍依赖服务端版本或幂等保护；本轮串行修复针对已识别高影响重复创建/全表覆盖窗口，不声称所有 UI 写操作都使用同一个全局锁
