# T03 功能下线与历史数据

本次移除突发状况、变更集、网页聊天与文件提取、个人记忆、Rust 桥、收集箱、个人演示项目、内部组织分组、团队模板、人员技能标签、基本资料编辑撤回及定时日报。相关页面、接口、工具目录和模板字段同步退休。

保留项目问题、突发停工、车辆问题履历、人员不可用时段、操作记录、项目回收站、周报、问题超时提醒及通知投递。旧归档快照和文件引用保护在本 v3 继续只读保留；停止自动物理清理，管理员在回收站生成加密备份后才可明确永久删除。具体迁移、权限和下载规则见 [项目回收站与永久删除](project-retention.md)。

T40 同步退休按日日程、自动重排、范围/工期修改和甘特图；旧 HTTP 入口认证后返回 410。原日程、负责人、数量、发布状态和工期策略保留只读来源，当前安排改用[周计划](weekly-plans.md)，不把旧日程当作实际发生或永久交接义务。

按日排程退役后，个人临时日程的新增、修改、删除入口同样认证后返回 410；原条目只归所有者只读查阅，列表不再泄露所有者已无权查看项目的当前名称。按日数量统计、人员看板、分配冲突检查与北极星准时率端点一并返回 410。旧个人日程仍关联的项目暂不能永久删除，需管理员按备份流程处理（待产品确认清理策略）。

## 迁移前后的核对

Alembic 的 T03 迁移先保全旧记录，再核对正式项目、账号安全字段和原附件。缺少原文件、加密导出失败或核对不一致时，数据库迁移中止。

- 正式项目和账号不会因功能下线而删除；角色、会话版本及真实权限保持。
- 突发状况关闭时写系统迁移审计；原始状态、完整记录及处置流水保存为该项目的历史 CSV 附件。
- 已明确归属的收集箱文件复用原项目附件或进入项目未归类文件；无法确认归属的文件按上传者隔离加密保存，不采用 AI 推测的项目。
- 私有聊天、记忆和个人演示项目的记录及文件按所有者隔离加密导出，不进入普通项目资料。
- 完成数据库迁移后，再次验证加密导出；仍被项目、模板或旧归档引用的文件保留。只有已导出且无剩余引用的原文件才清理。

## 管理员读取历史导出

证据位于部署数据目录的 `migration-exports/t03/`，不通过网页或 Agent 发布。目录清单记录每份导出、文件哈希、逐项去向和清理结果；加密文件使用 AES-256-GCM，密钥由原部署的持久 `SECRET_KEY` 派生。升级前必须独立保管原密钥及一致系统备份；密钥不包含在导出中。

在后端环境使用以下命令查看文件目录；需要读取内容时增加 `--destination` 指定一个尚不存在的私有目录。

```bash
python scripts/read_v3_retirement_export.py /data/migration-exports/t03/owners/OWNER/EXPORT.agvr \
  --secret-key-file /secure/original-secret.key
```

历史导出用于追溯；不重新开放退休接口，也不代替完整系统恢复。旧版本说明的原件已保存在本次受控交付证据中，当前操作以现有页面及手册为准。

## 只做记录：人员管理下线（3.5.5）

所有账号都能看、都能记录所有项目，系统只记下实际发生了什么、是谁记的，不再安排人：

- **下线的页面和操作**：人员页（团队周排班、请假/不可用登记，`/pm/people` 及 `/pm/my-schedule`、`/pm/team-schedule` 跳回工作台）；周计划格的“计划负责人”；工作台的“认领”和“协助登记”；问题的“指派处理人”；资料的“指派负责人”；项目设置里的成员名单、成员权限开关和项目协管。
- **规则**（`OPEN_PROJECT_ACCESS`，默认 `1`）：每个启用账号自动是每个项目的成员——建项目、改项目、导入/转移项目时补上全部启用账号；新建或重新启用账号时加入全部项目（账号上一条操作记录）；启动时核对一次旧项目（每个项目一条“所有账号可见所有项目：加入 …”记录）。从不因此移除成员。已发布的周计划不认领即可登记；任何项目成员都可以开始处理、提交问题结果，开始处理的人记为处理人；关闭和作废仍限报告人、项目负责人或管理员。项目负责人、技术负责人和管理员仍维护工作项、周计划和项目设置。
- **保留的数据**：已有的周计划负责人、认领、协助记录、问题处理人、资料负责人、成员权限和协管授予原样保留，后端规则照常生效，只是页面不再显示或修改；请假/不可用时段保留在数据库，可在管理员接口或备份中查阅。
- **恢复旧规则**：部署环境设 `OPEN_PROJECT_ACCESS=0` 后，后端恢复“仅项目成员可见、须认领、须指派”的规则（开启期间加入的成员不会自动移除）；页面不再提供认领、指派和成员维护入口，需要时通过旧接口或回退版本处理。
