# 全站排版与响应式调整

## 布局规则

- 全站导航在进入项目时默认收窄，保留图标与展开按钮。项目导航收至204px，正文获得更大空间。导航内容可独立滚动，管理入口不会被截断。
- 页面按标题与主要操作、筛选栏、内容区组织。项目列表的创建操作与搜索筛选分开，并提供清除筛选。
- 共用标题、留白、卡片、表格行距、表单标签、分页、标签页和弹窗规则集中于 frontend/src/styles/layout.css；颜色跟随主题变量。
- 宽表格在自己的区域滚动，页面本身不横向漂移。手机弹窗限制正文高度，底部操作区保持可访问。
- 项目启动提醒收成一行，减少每个页面重复说明占据的首屏空间。
- 模板中心在手机上使用可搜索的方案选择器，实施流程更早出现；导入、导出及删除收进更多操作。
- 项目创建步骤在手机上采用紧凑横向布局；320px宽度也不截断步骤或按钮。
- 修复项目卡片和表格进度条被 Space 包装挤压的问题；修复深色卡片标题不可读，补充深色链接、筛选占位文字和选项轨道颜色。
- 用户、车型、人员、模板和AI接口页面复用标题层级。现场导航增加当前页面语义，提供键盘跳转正文入口。
- 登录页去掉重复的忘记密码入口。

## 验证

- 390px：15个管理/现场入口、16个项目子页、7个管理员入口，共38条路线检查。表格/标签页的内部滚动区域允许横向滚动，未发现其他内容超出视口。
- 320/768/1024/1440px：项目列表、模板、用户、项目计划、现场填报共20种组合检查。
- 320×568px创建弹窗：正文宽264px、scrollWidth264px，底部按钮下缘539px，位于视口内。
- 1440px项目正文实测约1077px；暗色项目卡片标题为rgb(232,239,237)，进度条正常占据可用宽度。
- 前端47个文件、242项回归通过。生产构建通过。
- 截图见 screenshots/layout-2026-09-16：项目桌面、项目列表手机、模板手机、创建弹窗、深色列表。

以现有开发数据进行布局检查，不能覆盖任意长度内容和所有业务数据组合。没有修改生产业务数据或后端接口。
