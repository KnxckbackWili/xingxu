# 术语表

本文是 v3 文档的业务名称入口；精确字段和权限以当前接口及各主题规则为准。历史过程说明中的旧名不自动恢复已退役能力。

## 界面统一名称

以下覆盖任务书第 3 节全部 14 条名称。旧业务原文、冻结迁移字段和兼容 URL 可保留来源；新菜单、固定提示与通知使用右侧统一名称。

| 统一名称 | 含义 | 旧说法的对应 |
|---|---|---|
| 资料清单 | 项目内按阶段列出的全部资料要求及其提交情况 | 提交资料、交付物、归档清单、全部文件（入口名） |
| 资料要求 | 模板或项目中定义的一份应交资料，含名称、阶段、模板编号与输出时机 | 交付要求、归档项 |
| 输出时机 | 相对事件、每周、事件触发、完成后、按需、全周期等截止规则 | — |
| 关键事件 | 内部启动会、发车、逐台到场、签收、调试完工、上线、培训、验收、交付等业务事实 | 单一“计划进场日期” |
| 车辆进度表 | 车辆 × 环节的完成日期与完成人记录 | 单车调试数量填报 |
| 生命周期表 | 每台车的问题履历（模板 9） | — |
| 签单 | 到货签收单、调试完工单、上线运行单、培训记录表（模板 15–18） | — |
| 本周 | 实施工程师的主页面 | 今天（页面名） |
| 周计划 | 按周安排工作和人员的计划 | 甘特图、日程（按天排程） |
| 发布 | 将周计划发给相关人员 | 确认下达、下达 |
| 批准风险进场 | 资料未齐备时，授权人填写理由后允许进场 | 强制确认 |
| 外部查看 | 客户等外部人员的只读入口 | — |
| 保密资料 | 仅指定人员可见，外部始终不可见 | — |
| 准备 | 项目建档到进入现场实施，合并原初始状态、筹备和待进场 | 草稿、准备中、计划中、筹备、待进场（项目状态） |

模板自身的“草稿”、本地未保存草稿、日期边界的“今天”仍表达对应含义，不当作项目状态或页面旧名机械替换。模板阶段名与项目状态分别命名，历史原始值保持可追溯。

## 数据与操作边界

| 术语 | 含义与边界 |
|---|---|
| 项目状态 | 准备、现场实施、验收中、已完成、已归档，另有突发停工。由获授权的人明确推进，百分比、上传或填报不自动推进。 |
| 计划日期 | 预计安排，可用于估计截止；不证明事件已发生。 |
| 实际日期 / 实际时刻 | 来自真实业务的日期或带时区时刻。逐车到场与签单可只有日精度，不能补造午夜作为发生时刻。 |
| 登记时间 | 谁何时在系统记录事实，与实际执行日期、实际执行人分别表达；旧来源未知时保持未知。 |
| 现场时区 | 项目采用的本地日历、当周和截止规则；存储 UTC 时仍保留日期精度与时间依据。 |
| 工作项 | 项目中需要执行的工作。车辆环节按真实车号登记；非车辆工作的完成规则不与历史数量混成同一单位。具体周计划与本人执行入口待 T33/T40 最终说明。 |
| 检查项 | 对工作或实际车辆的质量、安全核对。安全检查不能用不适用或普通理由覆盖；普通覆盖仍需说明和审计。 |
| 项目资料规则 | 创建项目时取得的规则快照，后续模板修改不回写已建项目。 |
| 资料实例 / 期次 | 项目中真实需要提交的一项，例如本周、真实车辆或真实事故触发的资料。周次、触发事实和生效前义务不能凭空补造。 |
| 已提交 | 有真实本项目附件版本的提交事实。可选审核可通过或退回，不把审核意见当作另一个提交来源。 |
| 不适用 | 有明确理由的免交决定，保留操作者与依据；不能直接伪造 submitted。 |
| 未归类文件 | 已上传到本项目、尚未对应资料项的真实文件；可在授权范围内明确关联。 |
| 待分类旧资料 | 旧任务交付物、归档或准备来源被逐项保留，但不能安全推定新清单归属。分类前保留源阶段、原提交/审核与文件，不按同名或旧序号猜映射。 |
| 文件版本 | 指向真实原件的不可变提交记录。一份原件可对应多项要求，下载和生成都检查独立文件与全部资料家族的共同 ACL。 |
| 空白模板 | 独立归属的模板资产。只有编号不代表已有原件；不得硬绑虚构项目或任务。 |
| 保密范围 / 资料家族 | 资料规则与其全部期次、版本共同施加的当前可读范围；附件还可能有独立限制。角色、上传者或旧授权本身不提供隐式放行。 |
| 闭环问题 | 只有关闭或作废算闭环，已解决仍需核对；事故/质量性质另有真实触发和可配置 SLA。 |
| 清理凭据 | 明确授权移除旧周原件的 receipt/tombstone，保留原名、SHA、提交事实、谁何时按何策略清理；不声称原字节仍可下载。普通缺失不能冒充策略清理。 |
| 回收站 / 永久删除 | 普通删除可恢复且不会到期自动物理清除；永久删除另需完整加密备份、范围校验和明确确认。 |
| 便携方案 / 完整备份 | JSON/Excel/项目克隆用于复用计划和保留只读来源，新项目重新提交真实证据；一致加密备份用于完整恢复原数据库、文件与安全状态。 |
| 只读账号 / 外部查看 | 只读账号仍需项目可见权限；外部链接是独立、到期、可撤销的只读授权，默认项目/车辆进度，保密资料永不对外。 |
