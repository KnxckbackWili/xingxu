# 术语表

| 词 | 意思 |
| --- | --- |
| 项目 | 一次 AGV 实施。只有“进行中”和“已结束”两种状态，谁都能切换。已结束的项目不算缺口。 |
| 车辆 | 项目里的一台车。“车辆编号”必填，同一项目内不能重复。 |
| 环节 | 车辆表里的一列，例如到货点检、调试、交付。每台车逐个打勾。 |
| 车辆记录 | 一台车的一条变更、故障或维修记录。公司“AGV 生命周期表”的每一行就是一条车辆记录。 |
| 工作 | 项目里要做的一件事，按阶段分组，只有做完和没做。 |
| 问题 | 现场发现的问题，只有没关和已关。可以挂照片和文件。 |
| 资料 | 项目要交的一份资料。这一项下面有文件就是“已交”，没有就是“没交”。 |
| 其他文件 | 资料清单以外的文件，例如质量问题反馈单的扫描件。 |
| 物品 | 要带到现场或采购的一样东西，只有到了和没到。 |
| 缺口 | 还没做完的东西。全系统只有五条规则，见下。 |
| 模板 | 四张清单：工作、资料、车辆环节、物品。新建项目时复制进项目，之后互不影响。 |
| 车型库 | 型号名称的清单，录车时“型号”一栏从这里选。 |
| 操作记录 | 谁在什么时候改了什么。只增不改。 |
| 回收站 | 被删除的记录和项目保留 30 天，期间可以恢复，到期自动清除。 |
| 系统管理员 / 员工 | 仅有的两种账号。员工能做除“设置”以外的一切。 |

## 五条“缺”的规则

| 列 | 算缺的条件 |
| --- | --- |
| 车辆 | 这台车还有任何一个环节没打勾 |
| 工作 | 工作没打勾 |
| 问题 | 问题没关 |
| 资料 | 资料清单里的某一项下面没有文件 |
| 物品 | 物品没有勾“到了” |

规则在后端 `backend/app/services/gaps.py`，项目页的页签数字按同样的规则在前端 `pages/project/context.ts` 计算。

系统里没有计划日期、截止日期和逾期。打勾时自动记下是谁、哪天点的。
