# 使用说明

## 首页

登录后看到的是一张表：一行一个进行中的项目，五列分别是车辆、工作、问题、资料、物品还差多少。

- 点任何一个数字，直接进入那个项目的对应页签，并且只显示没做的。
- 点项目名前面的箭头，逐条列出具体缺什么。
- 右上角“新建项目”：填名称，选一个模板，填车辆台数。
- 已结束的项目收在页面底部。

## 项目页

五个页签：车辆、工作、问题、资料、物品。页签上的数字是还差多少，齐了显示对勾。

所有页签的操作方式相同：

- **改**：点格子直接改，按回车或离开格子自动保存。按 Esc 放弃这次修改。
- **加**：每张表最后一行直接打字，回车就新增。
- **打勾**：点一下。再点一下取消。鼠标移上去能看到是谁、哪天点的。
- **删**：每行末尾的“⋯”里有删除。删除后底部出现“撤销”；之后 30 天内还能在操作记录里恢复。
- **调顺序**：电脑上拖行首的把手；“⋯”里也有上移、下移。
- **只看没做的**：页签右侧的开关。

别人改的内容约 4 秒内自动出现，不用刷新。两个人改同一行的不同格子互不影响；改同一格时，后保存的人会看到提示，选“用我的”或“用对方的”。

### 车辆

一行一台车，一列一个环节。点环节名可以整列打勾、改名、移动、删除；“加环节”新增一列。

点车辆前面的箭头展开这台车的**车辆记录**。“导入”可以读入公司的 AGV 生命周期表或车辆表，导入前会先告诉你将新增几台车、几条记录；“导出生命周期表”得到公司格式的 Excel。

### 问题

最上面一行写一句话回车就上报。点“没关 / 已关”切换状态。每个问题可以拍照或上传文件。

### 资料

上半部分是要交的资料清单，在某一项后面上传文件（或把文件拖到这一行）就算交了。这个项目不需要的资料直接删掉那一行。清单以外的文件放在“其他文件”里。

## 模板和车型库

一个模板是四张清单。新建项目时选一个模板，清单复制进项目，之后项目和模板互不影响。模板可以复制、导出成 Excel、从 Excel 导入。员工也能改模板和车型库。

## 操作记录

谁在什么时候改了什么，可以按项目、按人筛选。被删除的记录旁边有“恢复”按钮。

## 设置（只有系统管理员）

- **账号**：新建、改姓名、设为系统管理员或员工、停用、重置密码。
- **备份**：设置备份口令后可以手动备份、下载。见[加密备份](encrypted-backups.md)。
- **软件更新**：检查并安装新版本。见[软件更新](software-updates.md)。
- **已删除的项目**：30 天内可以恢复。

每个人都可以在右上角头像里修改自己的密码、退出登录，旁边的按钮切换浅色和深色。

## 手机

手机上每一行变成一张卡片，打勾是一排大按钮，导航在屏幕底部。没有网络时页面会提示，已填的内容留在格子里，恢复网络后再保存；系统不做离线排队。
