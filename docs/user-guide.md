# 使用说明

按当前工作选择一页说明：

- [项目经理](quickstart-project-manager.md)：资料、车型、成员、关键事件和人工状态推进。
- [实施工程师](quickstart-engineer.md)：真实车辆环节、检查、问题、资料和上传队列。
- [管理员](quickstart-admin.md)：账号预设、二次验证、加密备份、回收站和存储。
- [外部人员](quickstart-external.md)：到期的只读链接和允许查看的内容。

完整主题入口见[文档目录](index.md)，名称见[术语表](glossary.md)。旧长手册属于 v2 历史材料，已与 QA 原件一起[归档](evidence-archive.md)；其旧数量填报、准备清单和自动推进说明不再作为当前操作指引。
