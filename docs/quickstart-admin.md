# 管理员一页说明

系统管理员做员工能做的全部项目工作，另外负责系统维护；保密资料仍按保密范围核对。

1. **建立账号。** 在账号页新建账号，默认是员工；只有需要维护系统的人设为系统管理员。不再使用某人时停用账号。
2. **维护账号安全。** 使用独立密码，按二次验证页面绑定并妥善保存一次性恢复码。账号停用和会话变化会重新校验；系统管理员身份不自动获得保密原件。
3. **核对配置。** 设置年度节假日时使用对应年份的完整来源；通知渠道按实际需要配置。维护密钥、更新令牌和备份口令，不在工单、日志或截图中展示。
4. **备份与恢复。** 先配置独立备份口令，再生成含数据库、实际原件及保全资料的一致加密备份。恢复按受管流程核对 SHA、口令和版本；计划 JSON/Excel 是便携方案，不能代替完整备份。测试只用隔离副本和专用库，pytest 会清空表。
5. **管理存储。** 查看全局及分项目占用；周资料默认保留最近 8 期，按策略先预览候选，再明确确认。当前/最近期、里程碑、其他引用和归档归属会保护原件；预览后变化需重新核对。已授权清理的旧原件会保留凭据，历史下载明确提示已清理。
6. **回收与更新。** 删除项目先进入回收站，可恢复；永久删除前核对完整加密备份和确认范围。软件更新先检查来源与备份，再由宿主受管服务执行；失败按恢复指引处理，不能只看安装按钮成功。
