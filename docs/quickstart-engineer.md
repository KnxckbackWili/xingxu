# 实施工程师一页说明

先由项目负责人把你加入实际项目，并授予对应操作权限。下列入口基于已实现的车辆、问题和资料模块；本人/周计划的最终导航与执行步骤待 T33/T40 稳定补充，v3 尚未完成部署总验收。

1. **核对项目与日期。** 打开获准的项目，确认现场时区和正在执行的工作。计划日期、实际完成日期和登记时间分别保存；不补造未知日期或车号。
2. **登记真实车辆环节。** 在车辆页找到实际车号，勾选已完成环节并填实际日期；可多选车辆批量登记。取消已有记录须说明原因。安全检查必须真实通过，普通失败/不适用也要保留说明，不能用勾选进度替代检查。
3. **上报并跟进问题。** 填真实现象、性质、涉及车辆和需要的照片；事故/质量性质会产生相应资料和时限。按授权处理、填写解决说明；“已解决”仍等待关闭核对，只有关闭/作废才闭环。
4. **提交资料。** 在资料清单选择自己负责的当前项，上传文件或选本项目已有真实附件；核对期次和真实车号。一份文件可交多项，历史版本保留。没有模板附件时先向负责人索取，编号不代表系统已有空白文件。
5. **处理上传队列。** 大文件分片上传可续传；断网、刷新或失败后在队列中核对并继续。若浏览器无法保留本地原件，按提示重新选择原文件；本地等待不等于服务端已提交，成功后在资料版本里核对。
6. **准备离场交接。** 把未完成事项和真实资料交给负责人；移出项目的提醒、交接资料按当前实际人员执行。无权限、账号切换或项目状态变化后，旧队列仍需重新授权。

保密文件只在负责人明确授权范围内可读，不能因上传者或管理员身份推定可见。操作被拒时联系项目负责人核对权限；不要为绕过拒绝复制成公开资料。详见[车辆](vehicle-progress.md)、[资料](project-documents.md)、[上传队列](resumable-storage.md)。
