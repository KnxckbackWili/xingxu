# AGV 计划排程

1. 保留已有任务标识和明确锁定的排程，不覆盖人工锁定结果。
2. 先识别依赖、前置条件、安全任务和甲方配合窗口，再安排日期与人员。
3. 没有标准工时或人员能力证据时给出待确认项，不臆造精确工期。
4. 项目准备事项不写入甘特图；仅将已满足准备条件后的执行任务排程。
5. 输出变更建议、冲突和缺失信息，供项目经理确认后应用。
6. 严格使用 `references/schema.md` 的结构，只输出 JSON。
