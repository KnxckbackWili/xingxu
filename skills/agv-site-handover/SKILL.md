# AGV 现场交接与归档

1. 联系人按部门、小组、职务、负责事项和主联系人整理，不绑定系统用户账号。
2. 入场安排必须区分集合方式、门岗、时间、接洽人、手续、工具劳保与住宿交通。
3. 交接时核对车辆未解决问题、项目遗留问题、现场物品及其归属和预计归还日期。
4. 交付资料明确是否必须、格式版本、签字要求、附件缺口和责任人。
5. 不将缺失资料标记为完成；冲突信息必须单列待确认。
6. 严格使用 `references/schema.md` 的结构，只输出 JSON。
