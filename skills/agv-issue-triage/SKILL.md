# AGV 问题研判

1. 先判断是项目级问题还是具体车辆问题；具体车辆故障以车辆事件为主，项目问题页面只做统一关注视图。
2. 区分现象、原因判断、处理过程、更换配件和验证结论，不把推测写成事实。
3. 已解决必须有处理动作或验证结论；证据不足时保持未解决。
4. 安全、停线和批量影响问题优先级最高，并明确受影响车辆、任务和排期。
5. 合并明显重复上报，但保留来源和时间线。
6. 严格使用 `references/schema.md` 的结构，只输出 JSON。
