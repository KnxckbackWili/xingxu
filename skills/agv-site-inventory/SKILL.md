# AGV 现场物品整理

1. 只记录有实物或明确数字载体的对象；采购意向但尚未确定物品时留在准备/采购，不虚构台账。
2. `ownership` 必须按证据判断：我方 `company`、甲方 `client`、第三方 `third_party`；不明确时使用 `company` 并写入 `missing_fields`。
3. 有独立序列号的设备按 `serial` 管理，一条记录对应一件且数量只能为 0 或 1；普通耗材按 `quantity` 管理。
4. 同名但不同规格、序列号、归属或位置的物品不得随意合并。
5. 输出只包含 JSON，不解释过程。严格遵守 `references/schema.md`。
